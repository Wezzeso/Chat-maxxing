# README banner sources

The README uses a minimal 3:1 banner. Light and dark versions are selected
automatically through GitHub's color preference.

- `banner-light.png`: 2172 × 724, off-white background.
- `banner-dark.png`: 2172 × 724, graphite background.
- Generated using the built-in imagegen tool.
- The previous app illustration was used only as a logo/color reference.
- Service logo sources and credits: [ICONS.md](../ICONS.md).

## Light banner prompt

```text
Use case: ads-marketing.
Asset type: ultra-wide GitHub README header BANNER, 3:1 landscape, 1800 x 600 pixels. This must be a shallow horizontal masthead, not a screenshot presentation.
Primary request: Turn the messaging project cover into an extremely minimal, Apple-inspired typographic banner.
Input image 1: reference for the five existing service logos and their brand colors ONLY. Do not reproduce the app window, sidebar, screen or screenshot.
Layout: one balanced horizontal composition. The word "Messages" sits near the left third, aligned on the same visual center line as a compact row of five service logos on the right. Very generous empty space above and below. Clear safe padding of 100 pixels at both edges. All elements centered vertically. No text above or below the banner.
Text verbatim: "Messages". This is the only text. Use refined neutral sans-serif typography, medium weight, clean kerning, about 76 pixels tall at 1800px output width. No effects.
Five symbols: WhatsApp green, Telegram blue, Instagram pink, LinkedIn blue, Gmail red, in exactly that left-to-right order. Each symbol about 44 pixels tall, separated by about 36 pixels of empty space. Keep the existing recognizable logo geometry. No text labels, circles, rounded-square tiles, button containers, or extra icons. These logos are tiny accent marks, not the dominant subject.
Style: restrained Apple editorial style, flat, precise, crisp and quiet. One solid background with no texture. This is a banner graphic, not a device mockup.
Avoid: app screenshots, large blank windows, title bars, UI panels, computers, phones, Apple logos, emojis, app logos, badges, taglines, feature lists, gradients, glow, reflections, 3D, glass, shadows, borders, rounded corners, decorative shapes, textures, watermarks.
Output one single finished 3:1 banner.
Theme: light. Flat off-white #F5F5F7 background; dark graphite #1D1D1F title. Preserve the brand colors.
```
